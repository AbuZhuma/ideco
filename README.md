# Ideco

Лёгкое Flutter-приложение: диктуете на русском - получаете точный текст в заметке.
Заметки объединяются в блокноты, текст можно править вручную.

## Что умеет

- **Диктовка на русском** через системный распознаватель (Google на Android, Apple на iOS) -
  наиболее точный вариант без тяжёлых моделей внутри приложения.
- **Непрерывная запись**: после паузы слушание продолжается автоматически, пока не нажмёте «стоп».
- **Умная обработка** на базовом уровне:
  - голосовые команды: «точка», «запятая», «вопросительный знак», «новая строка», «абзац»,
    «открыть/закрыть кавычки», «с большой буквы», «удалить последнее слово» и др.;
  - заглавная буква в начале предложения;
  - точка между фразами, произнесёнными с паузой (отключается);
  - правильные пробелы вокруг знаков препинания.
- Текст вставляется в позицию курсора; ещё не подтверждённый фрагмент подсвечивается.
- Блокноты: создание, переименование, удаление; заметки: поиск, перенос между блокнотами,
  удаление с отменой, «поделиться».
- Данные хранятся локально в одном JSON-файле, без сети и аккаунтов.

## Запуск

```bash
flutter pub get
flutter run            # на подключённом устройстве
flutter build apk      # Android release
flutter test           # тесты обработчика текста
```

Требуется Flutter 3.35+ (Dart 3.9+). Минимальная версия Android - та, что задана Flutter по умолчанию (API 21+).

## Структура

```
lib/
  main.dart                       # запуск, тема, локализация
  app_state.dart                  # состояние: блокноты, заметки, настройки, автосохранение
  models/                         # Notebook, Note, DictationSettings
  services/
    storage_service.dart          # JSON-хранилище в документах приложения
    speech_service.dart           # обёртка speech_to_text с авто-перезапуском
    text_processor.dart           # умная обработка: команды, заглавные, пробелы
  screens/                        # блокноты, заметки, редактор, настройки
  widgets/                        # кнопка микрофона, подсветка «живого» текста
test/text_processor_test.dart     # тесты обработчика
```

## Точность

Распознавание делает платформа, а не приложение, поэтому качество такое же, как у голосового
ввода Google/Apple. Для офлайн-работы на Android скачайте русский языковой пакет
(Настройки → Google → Голосовой ввод → Офлайн-распознавание). С интернетом точность выше.
